# 📚 Project Documentation & Assets

This directory contains all the non-code artifacts, academic documentation, and media assets for the **Edge AI Fall Detection System**. 

Keeping these files separated from the main source code ensures a clean and maintainable repository structure.

## 📂 Directory Contents

* **`/diagrams`**: System block diagrams and algorithmic flowcharts (created via draw.io).
* **`/proposal`**: The initial project proposal and requirements document approved by Dr. Yossi Golbatzov.
* **`/media`**: Screenshots, GIFs, and demo videos of the system in action (to be used in the final presentation).
* **`IEEE_Paper_Draft.pdf`**: The compiled draft of our academic paper (managed actively via Overleaf).

> **Note:** The LaTeX source code for the IEEE paper is managed separately on Overleaf to facilitate real-time collaboration. Only compiled PDFs and required image assets are stored here.
