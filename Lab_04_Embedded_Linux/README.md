Lab 4: Introduction to Embedded Linux 🐧OverviewThis laboratory serves as a foundational step into the world of Embedded Linux. As a final-year Electronics Engineering student, mastering the Command Line Interface (CLI) is essential for efficient hardware-software integration, system configuration, and managing resources on platforms like the Raspberry Pi.  The lab covers three main pillars of Linux system administration:Filesystem Navigation: Mastering the hierarchical structure of the OS.  Access Control: Understanding the Linux security model and permission management.  Process Management: Controlling task execution and system multitasking.  🛠️ Key Topics & Commands Covered1. File System NavigationPracticed traversing between home and system directories while managing environment paths.  Key Commands: cd, pwd, ls -al, more.Outcome: Demonstrated proficiency in absolute and relative path navigation.  2. Permissions & Access ControlExplored the Linux security model using octal notation to secure system files.  Key Commands: chmod, ls -l, mkdir, rm -rf.Outcome: Implemented read-only restrictions (444 / r--r--r--) and managed directory lifecycles, including recursive force-deletion of non-empty trees.  3. Process Management & Job ControlManaged asynchronous task execution, vital for running background hardware-monitoring scripts.  Key Commands: & (Backgrounding), jobs, fg, bg, kill, pkill.Outcome: Verified multitasking capabilities by toggling processes between foreground and background, and efficiently terminating multiple process instances by name.  📝 DeliverablesFull Lab Report: Lab_4__Introduction_to_Embedded_Linux.pdf
